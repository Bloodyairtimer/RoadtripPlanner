# Roam travel emblem

`roam-adventure.png` is the transparent logo used by the application sidebar and banner. It was generated for this project with the built-in image-generation tool.

Prompt: a compact fresh roadtrip emblem combining a turquoise-and-cream campervan, coral surfboard, palm tree, curling sea wave, mountain peaks and a yellow sun; crisp illustrated shapes, deep navy outlines, bright turquoise/ocean blue/yellow/coral palette, transparent background, no text or watermark.
